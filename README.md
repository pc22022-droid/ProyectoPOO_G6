# Sistema de Administración de Empleados

Proyecto de Programación Orientada a Objetos  
Universidad de El Salvador en Línea  
Grupo 6

## Descripción

Este sistema sirve para administrar los empleados de una empresa y calcular su salario según el tipo de contrato que tengan.

Hay tres tipos de empleados:

- Administrativo (salario fijo)
- Por Hora (se paga según las horas trabajadas)
- Por Comisión (se paga según las ventas)

Se usó Java, Java Swing para las ventanas y MongoDB para guardar la información.
